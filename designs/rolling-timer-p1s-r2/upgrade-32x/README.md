# Optional 32:1 development set - revision 2

Build the initial 16:1 mechanism first. This optional set keeps both carrier plates, the revised square drive and its round sleeves, drum, ballast and pendulum. Read the parent ASSEMBLY.md section "Trying 32:1 later" and layout-and-checks.json before printing.

U02-U04 now have pinion teeth extending through the large-wheel thickness, as in the revised base gears. The D compound still has its recessed collar seat; inspect that small annular overhang in the slicer. Use the reversed escape wheel and reversed anchor together. All upgrade print quantities and orientations are in parts.json. The geometry is not physically tested.
